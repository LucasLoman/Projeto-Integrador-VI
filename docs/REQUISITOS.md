# Requisitos iniciais do AutoStock

## Problema
Reduzir faltas de produtos e excesso de itens de baixa movimentação, apoiando decisões de compra com dados históricos.

## Requisitos funcionais
- RF01 Autenticar usuários.
- RF02 Cadastrar categorias, marcas, fornecedores e produtos.
- RF03 Registrar entradas, saídas e ajustes de estoque.
- RF04 Registrar vendas e baixar estoque automaticamente.
- RF05 Exibir histórico de movimentações.
- RF06 Exibir dashboard com indicadores.
- RF07 Identificar estoque abaixo do mínimo.
- RF08 Calcular curva ABC.
- RF09 Identificar produtos sem venda recente.
- RF10 Calcular consumo médio e cobertura de estoque.
- RF11 Estimar risco de ruptura.
- RF12 Sugerir quantidade de reposição.
- RF13 Gerar QR Code de acesso rápido ao produto.

## Requisitos não funcionais
- RNF01 Interface responsiva.
- RNF02 API REST.
- RNF03 Banco PostgreSQL.
- RNF04 Controle de versão Git/GitHub.
- RNF05 Execução via Docker.
- RNF06 Autenticação por token.
