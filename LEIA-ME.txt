TESTE: BACKEND

Branch sugerida:
test/backend

Source:
develop

Objetivo desta etapa:
Criar uma camada de testes de integração para verificar se os principais módulos
do backend continuam funcionando juntos após todas as features já desenvolvidas.

O que esta branch adiciona:
- Ambiente de teste separado usando SQLite em memória.
- Configuração do pytest para executar os testes do projeto.
- Testes de autenticação JWT.
- Teste de bloqueio de endpoints sem login.
- Teste de fluxo completo:
  cadastro -> entrada de estoque -> venda -> baixa automática -> análises.
- Teste de venda com estoque insuficiente.
- Teste de saída manual acima do saldo disponível.
- Smoke tests dos endpoints:
  * Dashboard
  * Curva ABC
  * Produtos parados
  * Previsão de ruptura
  * Sugestão de reposição

IMPORTANTE:
Os testes já criados durante as features, dentro de inventory/tests.py,
continuam sendo executados. Esta branch NÃO substitui esses testes:
ela adiciona testes de integração em backend/tests/.

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   test/backend
   Source: develop
4. Extraia este ZIP.
5. Copie a pasta backend para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Commit:
   test: adiciona testes de integracao do backend
8. Push origin.
9. Abra Pull Request para develop.
10. Faça o merge e apague a branch.

COMO EXECUTAR:
No terminal, dentro da pasta backend:

    pytest

Para saída mais detalhada:

    pytest -v

O pytest usará autostock.settings_test e criará um banco SQLite em memória,
então não é necessário ter o PostgreSQL ativo somente para executar os testes.

Arquivos desta branch:
- backend/autostock/settings_test.py
- backend/pytest.ini
- backend/tests/__init__.py
- backend/tests/conftest.py
- backend/tests/test_auth.py
- backend/tests/test_inventory_workflow.py
- backend/tests/test_analytics_smoke.py
