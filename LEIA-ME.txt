AUTOSTOCK - FEATURE/CADASTRO-PRODUTOS

1) No GitHub Desktop, fique na branch develop e faça Fetch/Pull.
2) Crie a branch feature/cadastro-produtos a partir da develop.
3) Extraia este ZIP.
4) Copie as pastas backend e frontend para a raiz do projeto AutoStock.
5) Quando o Windows perguntar, confirme a mesclagem/substituição dos arquivos.

Arquivos alterados nesta etapa:
- backend/inventory/serializers.py
- backend/inventory/views.py
- backend/inventory/tests.py
- frontend/src/pages/Products.tsx
- frontend/src/styles.css

Funcionalidades desta branch:
- Cadastro de produtos
- Listagem de produtos
- Edição de produtos
- Exclusão de produtos
- Pesquisa no front-end
- Pesquisa via API usando ?search=
- Validação de SKU e valores
- Destaque de estoque abaixo do mínimo
- Testes básicos de CRUD da API

Observação:
O campo quantidade permanece somente leitura no cadastro. A quantidade deve ser alterada pelo módulo de movimentação de estoque, que será implementado em outra branch.

Commit sugerido:
feat: implementa cadastro de produtos

Depois:
Push origin -> Pull Request para develop -> Merge -> excluir feature/cadastro-produtos.
