DEVOPS: DOCKER

Branch sugerida:
devops/docker

Source:
develop

Objetivo:
Padronizar o ambiente do AutoStock para que qualquer integrante consiga iniciar
frontend, backend e PostgreSQL com um único comando.

O que esta etapa adiciona:
- Docker Compose com 3 serviços:
  * PostgreSQL
  * Django
  * React/Vite
- Healthcheck do banco.
- Healthcheck do backend.
- Healthcheck do frontend.
- Volume persistente do PostgreSQL.
- Volume isolado para node_modules.
- Migrations automáticas ao iniciar o backend.
- Espera automática do PostgreSQL antes de iniciar o Django.
- .dockerignore para backend e frontend.
- Portas configuráveis por .env.

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   devops/docker
   Source: develop
4. Extraia este ZIP.
5. Copie:
   - docker-compose.yml
   - .env.example
   - pasta backend
   - pasta frontend
   para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Na raiz do projeto, crie o arquivo .env copiando .env.example.
8. Troque pelo menos:
   POSTGRES_PASSWORD
   DJANGO_SECRET_KEY

NO WINDOWS:
Você precisa ter o Docker Desktop instalado e aberto.

PARA SUBIR O SISTEMA:
Na raiz do AutoStock:

    docker compose up --build

Depois acesse:
Frontend:
    http://localhost:5173

Backend/API:
    http://localhost:8000/api

Admin Django:
    http://localhost:8000/admin

PARA CRIAR O USUÁRIO ADMINISTRADOR:
Com os containers rodando:

    docker compose exec backend python manage.py createsuperuser

PARA VER OS CONTAINERS:
    docker compose ps

PARA VER LOGS:
    docker compose logs -f

Somente backend:
    docker compose logs -f backend

PARA PARAR:
    docker compose down

PARA PARAR E APAGAR O BANCO LOCAL:
ATENÇÃO: esse comando apaga os dados do PostgreSQL do Docker.

    docker compose down -v

TESTES DENTRO DO DOCKER:
Backend:
    docker compose exec backend pytest

Frontend:
    docker compose exec frontend npm test
