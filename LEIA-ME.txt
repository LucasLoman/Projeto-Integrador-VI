TESTE: FRONTEND

Branch sugerida:
test/frontend

Source:
develop

Objetivo:
Adicionar testes automatizados para as principais telas React usando
Vitest + React Testing Library.

Esta etapa adiciona:
- Vitest
- jsdom
- React Testing Library
- jest-dom
- user-event
- cobertura V8
- teste da tela Produtos
- teste de pesquisa
- teste de cadastro de produto
- teste da página de QR Code
- teste de erro do QR Code
- teste de login inválido

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   test/frontend
   Source: develop
4. Extraia este ZIP.
5. Copie a pasta frontend para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Abra um terminal dentro de frontend.
8. Execute:
   npm install
9. Inclua o package-lock.json criado/atualizado no commit.
10. Execute:
   npm test
11. Para cobertura:
   npm run test:coverage
12. Commit:
   test: adiciona testes automatizados do frontend
13. Push origin.
14. Pull Request para develop.
15. Merge e apague a branch.

Arquivos desta branch:
- frontend/package.json
- frontend/vitest.config.ts
- frontend/src/test/setup.ts
- frontend/src/test/Products.test.tsx
