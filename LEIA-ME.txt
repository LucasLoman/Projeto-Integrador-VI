FEATURE: CADASTRO DE MARCAS

Branch sugerida:
feature/cadastro-marcas

Source:
develop

O que esta etapa adiciona:
- Tela de cadastro de marcas.
- Listagem, pesquisa, edição e exclusão.
- Link "Marcas" no menu principal.
- Validação para impedir nomes vazios/curtos.
- Validação para impedir marcas duplicadas ignorando maiúsculas/minúsculas.
- Busca por nome na API.
- Testes básicos de CRUD e pesquisa.

COMO APLICAR:
1. No GitHub Desktop, atualize a branch develop (Fetch/Pull).
2. Crie a branch feature/cadastro-marcas com source develop.
3. Extraia este ZIP.
4. Copie as pastas backend e frontend para a raiz do AutoStock.
5. Quando o Windows perguntar, escolha mesclar/substituir os arquivos existentes.
6. Revise as alterações no GitHub Desktop.
7. Faça o commit:
   feat: implementa cadastro de marcas
8. Push origin.
9. Abra Pull Request para develop.
10. Após o merge, apague a branch.

Observação:
A tabela/modelo Brand e a rota /api/brands/ já existem na base do projeto.
Esta branch completa a funcionalidade com interface, validações, busca e testes.
