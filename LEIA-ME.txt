FEATURE: QR CODE

Branch sugerida:
feature/qrcode

Source:
develop

O que esta etapa implementa:
- Botão "QR Code" na listagem de produtos.
- Tela individual do produto com QR Code.
- QR Code contendo o link direto para o produto no AutoStock.
- Consulta de SKU, estoque, localização, categoria, marca e fornecedor.
- Botão para baixar o QR Code em SVG.
- Botão para imprimir uma etiqueta.
- Layout de impressão próprio para a etiqueta.
- Redirecionamento após login: se o funcionário escanear o QR sem estar logado,
  o sistema leva ao login e depois retorna para o produto solicitado.
- URL configurável por VITE_APP_URL.

IMPORTANTE:
A biblioteca qrcode.react já está nas dependências do projeto inicial.
Não é necessária nova migration nem alteração no backend.

COMO FUNCIONA:
1. Na tela Produtos, clique em "QR Code".
2. O AutoStock gera uma etiqueta para aquele produto.
3. O QR contém um endereço como:
   https://seu-autostock.com/produto/15
4. Ao escanear pelo celular, o funcionário acessa diretamente o produto.
5. Se não estiver autenticado, faz login e retorna ao produto.

PARA TESTAR LOCALMENTE:
VITE_APP_URL=http://localhost:5173 funciona no mesmo computador.
Para escanear com outro celular durante desenvolvimento local, localhost do PC
não é acessível diretamente pelo celular. Use o endereço IP do computador na rede
ou, de preferência, teste após o deploy.

No .env, por exemplo:
VITE_APP_URL=http://192.168.0.100:5173

No ambiente publicado:
VITE_APP_URL=https://autostock.seudominio.com
