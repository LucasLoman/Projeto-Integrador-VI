AUTOSTOCK - FEATURE/CADASTRO-CATEGORIAS

BRANCH: feature/cadastro-categorias
SOURCE: develop

Esta etapa implementa o cadastro completo de categorias do AutoStock.

Arquivos alterados/criados:
- backend/inventory/serializers.py
- backend/inventory/views.py
- backend/inventory/tests.py
- frontend/src/App.tsx
- frontend/src/pages/Categories.tsx
- frontend/src/styles.css

Funcionalidades:
- Cadastro de categorias
- Listagem e pesquisa
- Edição
- Exclusão
- Validação de nome
- Bloqueio de categoria duplicada ignorando maiúsculas/minúsculas
- Pesquisa pela API usando ?search=
- Testes básicos da API
- Tela própria de Categorias no menu do AutoStock

COMO USAR:
1. No GitHub Desktop, atualize a develop (Fetch/Pull).
2. Crie a branch feature/cadastro-categorias com Source = develop.
3. Extraia este ZIP.
4. Copie as pastas backend e frontend para a raiz do AutoStock.
5. Quando o Windows perguntar, escolha mesclar/substituir os arquivos.
6. Confira os arquivos em Changes.
7. Commit sugerido:
   feat: implementa cadastro de categorias
8. Push origin.
9. Abra Pull Request para develop.
10. Faça o merge e apague a branch depois de confirmar que ficou correto.

Observação:
O modelo Category já existe na estrutura inicial, por isso não é necessária nova migration nesta etapa.
