FEATURE: REGISTRO DE VENDAS

Branch sugerida:
feature/registro-vendas

Source:
develop

O que esta etapa implementa:
- Registro de vendas com um ou vários produtos.
- Cliente opcional.
- Preço de venda preenchido automaticamente.
- Possibilidade de ajustar o preço unitário na venda.
- Cálculo automático de subtotal e total.
- Validação de estoque antes de concluir a venda.
- Bloqueio de produtos duplicados na mesma venda.
- Baixa automática do estoque.
- Geração automática de movimentação de saída vinculada à venda.
- Histórico de vendas.
- Visualização dos itens de cada venda.
- Pesquisa por número da venda, cliente, SKU ou produto.
- Testes para venda, total, baixa de estoque e estoque insuficiente.
- Transação atômica: se um item não puder ser vendido, a venda inteira é cancelada.

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   feature/registro-vendas
   Source: develop
4. Extraia este ZIP.
5. Copie as pastas backend e frontend para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Confira as alterações no GitHub Desktop.
8. Commit:
   feat: implementa registro de vendas
9. Push origin.
10. Abra Pull Request para develop.
11. Faça o merge e apague a branch.
