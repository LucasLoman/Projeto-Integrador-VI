COMO APLICAR:
1. No GitHub Desktop, use a branch que contém render.yaml (main, após deploy já integrado;
   ou devops/deploy, se ainda estiver aberta).
2. Extraia este ZIP e copie render.yaml, backend/ e docs/ para a raiz do repositório.
3. Substitua/mescle os arquivos quando solicitado.
4. Commit sugerido:

5. Push origin.
6. Se a correção foi feita em uma branch de trabalho, abra PR para main,
   aguarde os checks e faça o merge.
7. No Render, atualize/reabra a página de criação do Blueprint.
8. Confirme que a mensagem de erro sumiu antes de aplicar.

IMPORTANTE:
- Não copie a pasta externa fix_render_free_deploy para dentro do projeto.
- O .env com senhas não deve ser commitado.
- No plano gratuito, o Render não disponibiliza Shell; a criação do superusuário
  de produção precisará de um procedimento separado e seguro.
- O banco gratuito do Render expira em 30 dias (verifique a política atual).
