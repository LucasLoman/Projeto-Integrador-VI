CORREÇÃO DO BUILD DO AUTOSTOCK NO RENDER

Causa: o Render estava usando Python 3.14 por padrão, mas psycopg[binary]==3.2.6 não disponibiliza binários para Python 3.14.

Mudança: no render.yaml, o serviço autostock-api define PYTHON_VERSION=3.12.11.
A configuração anterior do plano gratuito (start.sh, sem preDeployCommand) é preservada.

COMO APLICAR
1. Extraia o ZIP.
2. Copie SOMENTE render.yaml para a raiz do repositório Projeto-Integrador-VI, substituindo o antigo.
3. No GitHub Desktop, faça commit: fix: define Python 3.12 para deploy no Render
4. Push para a branch. Confirme que a main recebeu a alteração, via Pull Request se necessário.
5. No Render, após sincronização do Blueprint, use Manual Deploy > Deploy latest commit, se não iniciar automaticamente.
6. No log do Render, confira que o Python escolhido é 3.12.x.

ALTERNATIVA SEM ZIP
No Render > autostock-api > Environment, configure a variável:
  PYTHON_VERSION=3.12.11
e realize novo deploy.

NÃO altere psycopg[binary]==3.2.6 neste momento; é compatível com Python 3.12.
