FEATURE: ESTOQUE MÍNIMO

Branch sugerida:
feature/estoque-minimo

Source:
develop

O que esta etapa implementa:
- Identificação automática de produtos no estoque mínimo.
- Identificação separada de produtos zerados.
- Status de estoque retornado pela API:
  * OK
  * ESTOQUE_BAIXO
  * SEM_ESTOQUE
- Cálculo do déficit até o estoque mínimo.
- Filtro na API:
  /api/products/?low_stock=true
- Filtro opcional por produto ativo/inativo.
- Nova tela "Estoque mínimo".
- Pesquisa por SKU, produto, fornecedor ou localização.
- Indicadores de quantidade de produtos em atenção e produtos zerados.
- Testes da API para filtro, status e déficit.

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   feature/estoque-minimo
   Source: develop
4. Extraia este ZIP.
5. Copie as pastas backend e frontend para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Confira as alterações no GitHub Desktop.
8. Commit:
   feat: implementa controle de estoque minimo
9. Push origin.
10. Abra Pull Request para develop.
11. Faça o merge e apague a branch.
