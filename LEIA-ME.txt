COMO APLICAR NO GITHUB DESKTOP:
1. Vá para develop.
2. Faça Fetch/Pull.
3. Crie:
   devops/deploy
   Source: develop
4. Extraia este ZIP.
5. Copie para a raiz do projeto:
   - render.yaml
   - backend/
   - frontend/
   - docs/
6. Mescle/substitua os arquivos existentes.
7. Faça commit:
   devops: prepara AutoStock para deploy no Render
8. Push origin.
9. Pull Request para develop.
10. Aguarde o GitHub Actions ficar verde.
11. Merge e apague a branch.

DEPOIS:
Faça o Pull Request final:

develop -> main
