FEATURE: MOVIMENTAÇÃO DE ESTOQUE

Branch sugerida:
feature/movimentacao-estoque

Source:
develop

O que esta etapa implementa:
- Entrada de produtos no estoque.
- Saída manual de produtos.
- Ajuste de inventário.
- Atualização automática do saldo do produto.
- Bloqueio de saída maior que o estoque disponível.
- Registro do usuário responsável pela movimentação.
- Custo unitário opcional nas entradas.
- Campo de observação.
- Histórico de movimentações.
- Pesquisa por SKU, produto ou observação.
- Filtro por tipo de movimentação.
- Testes de entrada, saída, ajuste e estoque insuficiente.

IMPORTANTE SOBRE "AJUSTE":
Ao selecionar "Ajuste de estoque", a quantidade digitada representa o NOVO SALDO.
Exemplo:
Estoque atual = 10
Ajuste informado = 8
Novo estoque = 8

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   feature/movimentacao-estoque
   Source: develop
4. Extraia este ZIP.
5. Copie as pastas backend e frontend para a raiz do AutoStock.
6. Mescle/substitua os arquivos quando solicitado.
7. Confira as alterações no GitHub Desktop.
8. Commit:
   feat: implementa movimentacao de estoque
9. Push origin.
10. Abra Pull Request para develop.
11. Faça o merge e apague a branch.
