FEATURE: DASHBOARD

Branch sugerida:
feature/dashboard

Source:
develop

O que esta etapa implementa:
- Dashboard principal do AutoStock.
- Total de produtos ativos.
- Quantidade de produtos com estoque baixo.
- Quantidade de produtos zerados.
- Total de unidades em estoque.
- Valor estimado do estoque pelo custo.
- Faturamento dos últimos 30 dias.
- Quantidade de vendas dos últimos 30 dias.
- Ticket médio dos últimos 30 dias.
- Gráfico dos produtos com maior faturamento.
- Lista de produtos em estoque crítico.
- Últimas vendas registradas.
- Lista de produtos sem venda nos últimos 90 dias.
- Botão para atualizar os indicadores.
- Testes da API do dashboard.

COMO APLICAR:
1. No GitHub Desktop, vá para develop.
2. Faça Fetch/Pull origin.
3. Crie:
   feature/dashboard
   Source: develop
4. Extraia este ZIP.
5. Copie as pastas backend e frontend para a raiz do AutoStock.
6. Mescle/substitua os arquivos existentes.
7. Confira as alterações no GitHub Desktop.
8. Commit:
   feat: implementa dashboard gerencial
9. Push origin.
10. Abra Pull Request para develop.
11. Faça o merge e apague a branch.
