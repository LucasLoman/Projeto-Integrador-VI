BRANCH: feature/cadastro-fornecedores
SOURCE: develop

Esta etapa implementa/melhora o cadastro de fornecedores do AutoStock.

Arquivos alterados:
- backend/inventory/serializers.py
- backend/inventory/views.py
- backend/inventory/tests.py
- frontend/src/pages/Suppliers.tsx
- frontend/src/styles.css

Funcionalidades:
- Cadastro de fornecedor
- Nome / razão social
- CNPJ
- Telefone
- E-mail
- Prazo médio de entrega (lead time)
- Listagem e pesquisa
- Edição
- Exclusão
- Validação básica de CNPJ
- Testes da API

COMO USAR:
1. No GitHub Desktop, atualize a develop (Fetch/Pull).
2. Crie a branch feature/cadastro-fornecedores com Source = develop.
3. Extraia este ZIP.
4. Copie as pastas backend e frontend para a raiz do AutoStock.
5. Quando o Windows perguntar, escolha mesclar/substituir os arquivos.
6. Confira os arquivos em Changes no GitHub Desktop.
7. Commit sugerido:
   feat: implementa cadastro de fornecedores
8. Push origin.
9. Abra Pull Request para develop.
10. Faça o merge e apague a branch após confirmar que tudo ficou correto.

Observação:
O modelo Supplier já existe na estrutura inicial do projeto. Por isso não há nova migration nesta etapa.
